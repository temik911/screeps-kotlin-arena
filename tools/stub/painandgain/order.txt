# Порядок списка в таблице — приоритет, и другого описания приоритета нет. Причина, по которой одна строка стоит выше
# другой, до 20.09.2026 жила комментарием между строками: переставил строку — комментарий остался, и не сломалось ничего,
# кроме решения, принятого двадцать версий назад. Здесь причина — запись, которую читает линт (правило `table_order`):
#
#     <таблица>: <строка, которая обязана стоять ВЫШЕ> > <строка ниже>   # версия или дата: почему
#
# Таблица — имя её счётчика в приборе `reach t=` (rung, step, gate, pass, posture, mode, cmdwhy, push); строка — её тег.
# Линт читает порядок тегов из исходника таблицы и сверяет: обе строки есть, первая выше второй, причина названа.
# Снял или переименовал строку — сними или перепиши запись; переставить строки вопреки записи значит отменить решение,
# и делается это правкой ЭТОГО файла вместе с таблицей, с новой причиной. Запись без причины линт не принимает.
# Начальный набор снят с комментариев между строками `ladder()`, `steps()`, `captureGates()` и `pushRules()` на v452.
